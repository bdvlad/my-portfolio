# Моя візитка

Адаптивний односторінковий сайт-візитка Василя Навчального, вайб кодера. Сторінка представляє фахівця в діловій стилістиці з легким гумором: про себе, навички, компетенції, послуги, відгуки та контакти.

Сайт працює у світлій і темній темі. Вибір зберігається в `localStorage`; якщо збереженої теми немає, береться системна (`prefers-color-scheme`).

## Технології

- HTML5 (семантика, якірні секції, skip-link)
- CSS3 (flex, grid, медіазапити, CSS-змінні для палітри обох тем)
- JavaScript (`js/theme.js` — перемикач світлої/темної теми без мерехтіння)
- Google Fonts: Cormorant Garamond (заголовки), Source Sans 3 (текст)

## Можливості

- Односторінкова навігація: про мене, навички, компетенції, послуги, відгуки, контакт
- Перемикач «Світла / Темна» у шапці
- Адаптивна верстка для широкого екрана і телефону
- Локальні секрети не потрапляють у репозиторій: `.env` зазначено в `.gitignore`

## Структура

```
my-portfolio/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── theme.js
├── .gitignore
├── test.env
└── README.md
```

| Файл | Призначення |
| --- | --- |
| `index.html` | Розмітка сторінки, попереднє застосування теми до завантаження CSS |
| `css/styles.css` | Стилі, палітри `:root` і `html[data-theme="dark"]` |
| `js/theme.js` | Клік по перемикачу, `aria-*`, запис теми в `localStorage` |
| `.gitignore` | Ігнорує `.env` |
| `test.env` | Локальний файл середовища. Значення з нього не публікувати і не копіювати в README |

## Запуск

Потрібен лише браузер.

1. Відкрий папку проєкту.
2. Запусти `index.html` подвійним кліком або через «Open with Live Server» у редакторі.

Локальний сервер (за бажанням):

```bash
python -m http.server 8765
```

Після цього сайт доступний за адресою [http://127.0.0.1:8765/](http://127.0.0.1:8765/).
